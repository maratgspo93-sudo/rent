# Rental Hub Երևան. իրական MVP

Ինչ կա. FastAPI + SQLite, տեքստից պարամետրերի հանում, գների նորմալացում (AMD/USD), կրկնօրինակների միավորում,
«հավանաբար տանտեր/միջնորդ» միավոր, կասկածելի էժան գնի նշում, հղումների թարմության ստուգում, Telegram հավաքիչ և ֆրոնտենդ։

## Գործարկում
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # լրացրեք արժեքները
python -m unittest              # 6 թեստ, աշխատում են առանց արտաքին գրադարանների
python -m app.seed              # դեմո տվյալներ (նշվում են «Դեմո»)
uvicorn app.main:app --reload   # http://127.0.0.1:8000
```

## Տանտերերի ուղիղ հայտարարություններ (հիմնական աղբյուր)
- `/submit`. տանտերը լրացնում է ձևը (շրջան, սենյակներ, գին, նկարներ, հեռախոս)։ Հայտարարությունը մտնում է **pending**։
- Մոդերացիա (CLI, առանց հանրային admin API-ի)՝ `python -m app.direct pending`, `approve ID`, `reject ID`։
  «pending» ցուցակում երևում է նաև հնարավոր կրկնօրինակի միավորը։
- Տանտերը ստանում է **կառավարման հղում** (`/manage#տոկեն`). այնտեղից «Դեռ ազատ է» կամ «Վարձակալվեց»։ Տոկենը բազայում պահվում է միայն հեշով։
- **Ժամկետանց.** 14 օր առանց հաստատման հայտարարությունը թաքցվում է. cron՝ `python -m app.direct expire`։
- **Միջնորդների զտում.** մեկ համարից 3-րդ հայտարարությունից սկսած պիտակը դառնում է «միջնորդ», 5-ից ավելին չի ընդունվում։ Պիտակը ինքնահայտարարությունից ավելի կարևոր է։
- **Նկարներ.** վերակոդավորվում են (EXIF/GPS-ը ջնջվում է), ընդունվում են JPEG/PNG/WEBP մինչև 5 ՄԲ, հաշվարկվում է dHash։
- Սահմանափակում՝ մեկ IP-ից 5 հայտարարություն ժամում (հիշողության մեջ. մի քանի սերվերի դեպքում՝ Redis)։

## Իրական տվյալներ (արտաքին աղբյուրներ)
1. **Telegram.** `TG_API_ID`, `TG_API_HASH`, `TG_CHANNELS` → `python -m collectors.telegram_collector`։
   Օգտագործեք միայն հրապարակային ալիքներ և հարգեք նրանց կանոնները։
2. **List.am.** Ադապտեր չկա դիտմամբ. նրանց օգտագործման պայմանները (list.am/help/14) արգելում են ավտոմատ մուտքը և բովանդակության պահպանումը։ Օգտագործեք միայն գրավոր համաձայնությամբ։
3. **Թարմություն.** cron-ով՝ `python -m app.freshness` (ոչ-Telegram) և `refresh_telegram()` (Telegram)։
4. **Փոխարժեք.** `app/fx.py`-ում դեռ `FX_USD_AMD` env է. միացրեք ՀՀ ԿԲ-ի տվյալներին։

## Հայտնի սահմանափակումներ
- Կրկնօրինակների կշիռները (`app/dedupe.py`) գնահատված են, ոչ թե իրական տվյալներով չափորոշված։ Փորձեք 200-300 հայտարարության վրա և ճշգրտեք։
  Անորոշ զույգերը (40-59) գրվում են `dedupe_review` աղյուսակում։
- Նկարները համեմատվում են dHash-ով. ջրանիշով կամ կտրված նկարները կարող են չհամընկնել։
- Telegram-ի ալբոմները (մի քանի նկար մեկ հաղորդագրությունում) դեռ չեն միավորվում. հավաքվում է միայն առաջին նկարը։
- Հեռախոսը չի պահվում, միայն sha256-ի կարճ հեշը (գործակալին ճանաչելու համար)։
- **Հեռախոսը չի հաստատվում** (SMS/Telegram կոդ չկա). մոդերատորը պետք է ձեռքով ստուգի կասկածելի հայտարարությունները։ Սա ամենակարևոր բացն է՝ ավելացրեք Telegram-բոտով համարի հաստատում։
- «Դեռ ազատ է» հիշեցումներ չկան (email/SMS չկա). տանտերը պետք է ինքը վերադառնա հղումով։
- Ձևի և նկարների կոդը (FastAPI մասը) չի գործարկվել այս միջավայրում, թեստավորված է միայն տրամաբանությունը (`app/direct.py`, 8 թեստ)։
- Քարտեզ դեռ չկա։ SQLite-ը բավարար է MVP-ի համար. մեծացնելիս՝ PostgreSQL + PostGIS։
